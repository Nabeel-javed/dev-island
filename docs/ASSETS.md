# Asset provenance

All island artwork is original and created in this repository:

- Pixel village: `src/lib/pixel-art.ts`, drawn using Canvas 2D and displayed through Phaser.
- Miniature island: `src/components/three-island.tsx`, built from primitive geometry and a custom roof shape.
- Logo, favicon and social illustration: inline SVG and authored shapes.
- Character previews: CSS shapes.

Original code and artwork share the repository's MIT license. The demo profile and its six repositories are fictional; their statistics are illustrative.

Third-party dependencies retain their respective licenses:

- DM Sans and Space Grotesk: SIL Open Font License, distributed locally by the `@fontsource` packages. Full notices remain in each package's `LICENSE` file.
- Lucide icons: ISC license, distributed by `lucide-react`; see its package `LICENSE`.
- Three.js, React Three Fiber, Drei and Phaser: MIT licenses, retained in installed dependencies.

No artwork is copied from Nintendo, Stardew Valley or commercial tilesets. No GitHub profile pictures or third-party images are included in downloadable postcards.
