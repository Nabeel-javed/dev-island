# Dev Island

Your code, a world of its own. A playable GitHub portfolio.

## Current milestone

Two matched playable previews: a cozy pixel island and a miniature 3D island. Select a visual direction before public launch.

## Development

```sh
pnpm install
pnpm dev
```

Open http://localhost:3100. Demo mode requires no credentials.

## Checks

```sh
pnpm typecheck
pnpm test
pnpm build
```

Built with Next.js, TypeScript, Phaser and React Three Fiber. Original procedural artwork; no external character packs.
